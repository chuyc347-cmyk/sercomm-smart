# SMART 目標檢核網站|中磊電子 SERCOMM

「績效管理」課程的課後練習工具。學員將自己或部屬草擬的績效目標貼上,
網站依 SMART 原則逐項檢核、給分,並提出具體改善建議、改寫句型與績效面談提問參考。

## 功能

- **五構面檢核**:具體 Specific、可衡量 Measurable、可達成 Attainable、相關 Relevant、有時限 Time Bound,各構面 0–100 分並標示「良好/部分符合/待加強」
- **證據標示**:列出在目標中偵測到的行動動詞、指標、數字、期限、方法等關鍵內容
- **具體改善建議**:針對缺漏構面給出可直接套用的改寫提示,並抓出「持續、大幅、積極」等模糊修飾詞
- **改寫句型**:自動把偵測到的內容套入完整目標句型(在【期限】前,透過【方法】,將【指標】由【現況】提升至【目標值】,以支持【上位目標】),可一鍵複製
- **面談提問建議**:依最弱構面產生一對一面談的教練式提問
- **職能範例**:硬體開發、軟體韌體、驗證測試、認證法規、生產製造、品保、採購供應鏈、專案管理、業務各一則優良範例,以及一則待改善範例
- **多條目標**:一行一條,可一次貼多條(例如整份部屬目標)
- **列印/存 PDF**:檢核結果可直接列印帶進面談
- 支援深色/淺色主題、手機版面;所有分析皆在瀏覽器內完成,**內容不上傳、不儲存**

## 技術

單一 `index.html`,純 HTML/CSS/JavaScript,無任何後端、外部套件或 API。
檢核邏輯為針對繁體中文目標語句設計的關鍵字規則引擎(見 `index.html` 內 `RE` 規則表),
另支援無單位數值指標、千分位數字(半形與全形逗號皆可,例如「由 2,100 Mbps 提升至 2,800 Mbps」),
以及「完成認證、送樣、量產」這類里程碑型目標的辨識。
可直接修改詞庫以貼合公司慣用指標(良率、直通率、不良率 ppm、RMA、MTBF、吞吐量、
傳輸速率、掉線率、封包遺失率、覆蓋率、訊號強度 RSRP/SINR、韌體升級成功率、
自動化測試覆蓋率、缺陷數、認證一次通過率、里程碑準時率、稼動率、換線時間、準交率、
缺料率、庫存週轉、BOM 成本等網通產業指標已內建,單位涵蓋台/萬台、Mbps/Gbps、
dBm/dBi、ms、GHz、W/mW、ppm)。

## 公開部署(GitHub Pages)

1. GitHub repo → **Settings → Pages**
2. Source 選 **Deploy from a branch**,Branch 選 `main`、資料夾選 `/ (root)`,按 Save
3. 約一分鐘後網站會發佈在 `https://<帳號>.github.io/<repo 名稱>/`

之後只要把這個網址(或 QR code)放在課程簡報最後一頁,學員即可直接使用。

## 本機預覽

直接用瀏覽器開啟 `index.html` 即可,無需安裝任何東西。
